# Земляной бур

Гидравлический земляной бур Avant — мощный инструмент для различных земляных работ, будь то бурение ям для столбов, пересадка деревьев или другие аналогичные работы.

## Доступные размеры

| Диаметр | Артикул |
|----------|----------|
| 100 мм | A33601 |
| 200 мм | A33609 |
| 300 мм | A33612 |

Все буры оснащены заменяемыми твердосплавными зубьями и направляющим остриём, обеспечивающими эффективную работу как в твёрдом грунте, так и в песчанике.

## Подходящие приводы

| Привод | Крутящий момент | Диаметр бура |
|------|-------------|----------------|
| Multi function drive unit (A37190) | 1355 Нм | 75–300 мм |
| HD 45 (A33552) | 2452 Нм | 75–600 мм |
| HD 58 (A33551) | 3017 Нм | 75–750 мм |
| HD 72 (A34032) | 3874 Нм | 75–900 мм |

При выборе привода учитывайте максимальный диаметр буров. Для буров большего диаметра рекомендуем высокопроизводительные планетарные приводы (серия HD).

## Подходящие работы

- Бурение ям для столбов
- Пересадка деревьев
- Установка столбов ограждения
- Монтаж дренажных систем

## Преимущества

**Мощный:** Гидравлический привод обеспечивает достаточную силу даже для более тяжёлых работ.

**Долговечный:** Заменяемые твердосплавные зубья и направляющее остриё обеспечивают длительный срок службы.

**Универсальный:** Различные диаметры подходят для многих ситуаций.

**Прост в использовании:** Быстро подключается к погрузчику Avant.

## Дополнительное оборудование

- Удлинитель 500 мм (A33546)
- Удлинитель 800 мм (A32532)
- Удлинитель 1000 мм (A33554)
- 2-сторонний поворотный адаптер для буров HD (A421877)
- Адаптер для винтовых свай (A418530)
